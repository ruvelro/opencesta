OpenCesta

Precios de Mercadona y Dia con histórico diario · dataset abierto en github.com/ruvelro/opencesta
Cargando la base de datos en tu navegador…
Todo se ejecuta en tu navegador con DuckDB-WASM sobre un único fichero Parquet: no hay servidor, no hay base de datos, y tus búsquedas no salen de tu equipo. Los precios son los publicados por cada cadena para la zona indicada. Datos bajo ODbL.
